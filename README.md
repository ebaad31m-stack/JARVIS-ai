# 🤖 JARVIS AI Assistant

JARVIS is a modular desktop AI assistant built with Python.

The goal is to create a powerful local assistant with voice control, memory, automation, vision, and AI capabilities.

---

## ✨ Features

Current:

- 🎤 Voice input
- 🔊 Voice output
- 🗣️ Wake word detection
- 🧠 Memory system
- 🧭 Intent routing architecture
- ⚙️ Configuration management
- 📝 Logging system
- 🛡️ Error handling

Planned:

- 🧠 Local AI with Ollama
- 👁️ Computer vision
- 📷 OCR
- 🖥️ Desktop automation
- 🧩 Plugin system
- 📱 Mobile companion app
